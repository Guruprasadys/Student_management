# Student Management System

## Description
A web application to manage **students, courses, attendance, and grades**.  
It allows admins to manage data and students to view their attendance and grades.

## Features
- Admin Dashboard for managing students, courses, attendance, and grades  
- Student login to view personal dashboard  
- Attendance tracking  
- Grade reports  

## Tech Stack
- **Backend:** Django  
- **Database:** SQLite  
- **Frontend:** HTML, CSS (basic)
